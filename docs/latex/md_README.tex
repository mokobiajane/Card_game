{\bfseries{\doxylink{classCard}{Card} RPG Lab}} is a turn-\/based card role-\/playing game where players battle AI-\/controlled enemies using character abilities, effect cards, and items.\hypertarget{md_README_autotoc_md9}{}\doxysubsubsection{\texorpdfstring{✨ Key Features}{✨ Key Features}}\label{md_README_autotoc_md9}

\begin{DoxyItemize}
\item {\bfseries{Diverse Character Classes}}\+: Warrior, Mage, Archer, Healer with unique abilities and characteristics
\item {\bfseries{Advanced \doxylink{classCard}{Card} System}}\+: Attack, defense, special effect, and spell cards
\item {\bfseries{Intelligent Opponents}}\+: Multiple AI levels (Easy, Advanced, Boss) with different strategies
\item {\bfseries{Status Effects}}\+: Burning, Poison, Regeneration, Slow, and other time-\/based effects
\item {\bfseries{Inventory System}}\+: Items, weapons, armor, and consumables
\item {\bfseries{Various Game Modes}}\+: \doxylink{classBattle}{Battle}, Dungeon, Exploration, Trading, PvP
\end{DoxyItemize}
